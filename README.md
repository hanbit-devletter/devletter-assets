# 데브레터 이미지 저장소

## 👉 [이미지 주소 복사하러 가기 (jsDelivr)](https://cdn.jsdelivr.net/gh/hanbit-devletter/devletter-assets@main/)

폴더 클릭 → 파일 이름 우클릭 → 링크 주소 복사

## 규칙
- 고정 이미지(아이콘, 피드백 배너): `fixed/`
- 주차별 이미지: `2026/11-2/` 처럼 연도/월-주차
- 파일 이름은 영문 소문자로
- 이미 올린 이미지를 고칠 때는 이름을 바꿔서 올리기 (예: img1-v2.jpg)
- 메일에는 꼭 cdn.jsdelivr.net으로 시작하는 주소를 쓰기
